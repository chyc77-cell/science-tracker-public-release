Getting started

How do I install ScienceTracker?

Download the installer ZIP from the official website or GitHub Releases. Extract the ZIP, run ScienceTracker_Setup.exe, and launch ScienceTracker from the Start menu or desktop shortcut. It normally runs in the Windows notification area (system tray), so check the hidden tray icons if no main window appears.

What do I need before the first launch?

Windows 10 or 11 (64-bit), an Internet connection, and the identifiers of the academic profiles you want to monitor. You can start with Google Scholar or ORCID/OpenAlex; a Scopus API key is only needed if you enable Scopus. For full ScienceTracker functionality, we recommend configuring all three academic profiles: Google Scholar, Scopus, and OpenAlex/ORCID. This enables the most comprehensive monitoring, cross-database comparisons, and advanced research analytics. Open the tray menu → Settings, enter your profile IDs, choose a check interval, then Save.

Where do I find my profile identifiers?

For Google Scholar, open your profile and copy the value of the user= parameter from its URL. For Scopus, use your numerical Scopus Author ID, not an article EID. For OpenAlex/ORCID, enter your 16-digit ORCID iD in the 0000-0000-0000-0000 format. Use your own identifiers; do not paste an entire URL into a field that expects an ID.

Where is the main window?

ScienceTracker is a tray application. Right-click or click its icon in the Windows notification area and select the option to view statistics. Use Settings to change profiles, check intervals, startup behavior, language, and Telegram connectivity.

How do I update ScienceTracker?

For the GitHub-distributed desktop edition, use the program's built-in version check or download the latest installer from official Releases. Keep a backup of your data before changing installation methods. A future Microsoft Store edition may use Store-managed updates instead.

Academic profiles and API access

Why does Scopus require an API key?

ScienceTracker accesses Scopus through the Elsevier API. Request a key at dev.elsevier.com and enter it in Settings.

Scopus works at my university but not at home. Why?

Elsevier may restrict API access outside your institution's network if your API key is institution-linked. To resolve this issue, we recommend registering for an Elsevier developer account using a personal email address and obtaining a new API key that is not linked to your institution. This may allow ScienceTracker to access Scopus from your home network. Alternatively, you can enter an Institutional Token in the optional field in ScienceTracker Settings. The token may be obtained from your institution or requested through Elsevier Support.

Why does Google Scholar sometimes fail to update?

Google Scholar is not a guaranteed public API for researcher profiles. Automated retrieval can fail due to rate limits, challenges, profile visibility, or website changes. Keep the check interval reasonably long, verify that the public profile loads in your browser, and try again later. Do not interpret an unsuccessful refresh as zero citations.

Why do Scopus, Google Scholar and OpenAlex show different totals?

The services cover different publications, citation sources, document types and author matches. ScienceTracker preserves each source's own metrics rather than adding them together. Check whether your profile has missing or duplicated records when the differences appear unusually large.

Do I have to configure every database?

No. Configure only the services you wish to monitor. Scopus-specific features need valid Scopus data; cross-source comparisons and estimated self-citations may require data from more than one configured source.

Statistics, quartiles and citation analysis

What does the “next h-index” analysis mean?

The analysis estimates how many additional citations selected existing publications would need for your next h-index value. It requires sufficiently complete publication-level citation data. It is a mathematical scenario, not a prediction that those citations will arrive, and the application may mark the estimate unavailable when data are incomplete.

How are publication types and SCImago quartiles assigned?

For Google Scholar, ScienceTracker uses bibliographic metadata, cross-source matches and available external records to classify works; quartiles are considered only for journal articles. Where possible, it matches journals using ISSN, year and journal information against locally cached annual SCImago data. Ambiguous or missing records may remain unclassified. The program uses an explicit category-resolution rule; its selected quartile should not automatically be treated as the journal's “SJR Best Quartile”.

Why does an article show “No quartile”?

Possible reasons include a missing ISSN or journal title, incomplete metadata, a journal absent from the matching SCImago year, or classification as a non-journal item. Review the DOI, publication year and journal information in the source profile. “No quartile” is not by itself evidence of poor journal quality.

How are self-citations estimated?

OpenAlex-based self-citation counting uses links between citing and cited works and matched author identities. Scopus self-citations are estimates derived from matched OpenAlex records, not official Scopus self-citation figures. Results depend on publication matching, OpenAlex coverage and author identity resolution. Read the match-coverage information shown by the application before interpreting the percentage.

What is “Scopus Coverage”?

It compares the works associated with your Google Scholar and Scopus profiles and identifies likely matches, uncertain records, and candidates that might warrant further investigation. It does not submit or approve Scopus document corrections. Verify candidates against their original bibliographic records before contacting Scopus.

What is the difference between citations by publication year and citations received each year?

The first groups today's total citations of works published in a given year; the second shows citations actually received in each calendar year. If Scopus Citation Overview access is unavailable, ScienceTracker may show the publication-year fallback. Read the note under the chart: these measures should not be treated as interchangeable.

Can I export research reports?

Yes. The Reports and profile Statistics features can generate Word documents when sufficient profile data are available. The reports include selected metrics and publications, with DOI links when the source provides them. Verify bibliographic completeness before using generated results in formal CVs or grant submissions.

Notifications, multiple PCs and updates

How do I connect Telegram?

In Settings → Telegram notifications, choose Connect Telegram, follow the browser/Telegram link, then press Start in the ScienceTracker bot. Return to Settings to confirm the connected state and use Send test. The test checks delivery, not citation-event deduplication.

Will I receive duplicate Telegram alerts from my home and work computers?

With ScienceTracker 6.0.2 or later on both computers and the corresponding updated notification backend, the same reported metric state is intended to be delivered only once per connected Telegram account. Both PCs still maintain their own local histories and unread indicators. An earlier installed version or a disconnected account may not have this protection.

Why did a Windows notification appear but no Telegram alert?

Windows notifications and Telegram are separate channels. Check the Telegram connection in Settings, send a test, and verify your Internet connection. A notification already sent from another PC may be intentionally suppressed by the Telegram backend. A test message is not subject to the same duplicate filtering.

How often should profiles be checked?

Use the interval in Settings; the minimum available interval is one hour. Frequent requests can trigger limits at upstream services, especially Google Scholar and OpenAlex. A longer interval is often more reliable for routine monitoring.

Does ScienceTracker synchronize histories across computers?

No. Each PC keeps its own local metric history. Telegram deduplication, when enabled, is a server-side delivery check and is not a general data synchronization or backup service.

Troubleshooting and privacy

Windows SmartScreen says “Unknown Publisher”. Is the installer broken?

A currently unsigned GitHub-distributed installer may display Unknown Publisher. Download only from the official release, confirm the repository and file name, and do not bypass security warnings for files of uncertain origin. A SmartScreen warning alone does not prove either that a file is malicious or that it is safe.

Why are statistics or charts missing?

First refresh the relevant profile. Some charts require publication-level metadata, a sufficiently complete work list, or authorized API endpoints. Scopus's calendar-year citation series may be unavailable without Citation Overview access. Reopen Statistics after the refresh and read the source/fallback note displayed near each chart.

Where are my history and cache stored?

In current builds (6.0.1+), the main history is stored at %LOCALAPPDATA%\ScienceTracker\stats_history.json. The application creates a backup file with a .bak suffix and stores other caches locally. Older releases may have used the installation directory. Keep copies of your files before reinstalling or troubleshooting.

Can I restore my old metrics history?

If an older installation has stats_history.json, keep a separate copy before upgrading. Current builds include migration and backup handling, but an upgrade is not a replacement for a personal backup. Never overwrite a newer working history with an older file without first saving both.

What data does the Telegram service receive?

When Telegram notifications are enabled, ScienceTracker sends the information needed for account linkage and alert delivery to its notification backend. Academic profile identifiers and metric-change details may be included in notification processing. Local citation history is not a shared cloud history. Consult the website's privacy information and disconnect Telegram if you do not wish to use this feature.

Where do I report a bug or request help?

Use the GitHub Issues page or the support contact listed in the application's About section. Include your app version, Windows version, source (Scopus, Google Scholar or OpenAlex), exact error text and steps to reproduce. Never post API keys or Telegram connection tokens publicly.
