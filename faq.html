Getting started

How do I install ScienceTracker?

Download the latest release from the official GitHub Releases page . If provided as a ZIP, extract it and run ScienceTracker_Setup.exe . Launch from the Windows Start menu or desktop shortcut. ScienceTracker normally runs in the system tray ; check hidden tray icons if the main window is not visible.

What do I need before the first launch?

Windows 10 or 11 (64-bit), an internet connection and the identifiers you plan to use. For Scopus, enter a numeric Scopus Author ID and an Elsevier API key . For Google Scholar, enter the profile's user= ID. For ORCID, enter the complete ORCID iD . You can configure sources independently; the full set of IDs gives the most complete Scopus and cross-source features.

Where can I find the profile IDs?

Scopus: the numeric Scopus Author ID, not a publication EID. Google Scholar: the value following user= in your public profile URL. ORCID: a 16-character identifier with check digit, such as 0000-0002-1835-0097 . Enter the identifier, not the full URL.

Where is the main window and what is the difference between Statistics and Reports?

Open the application from the Windows notification-area icon. The main dashboard displays Scopus , Google Scholar , and ORCID . Statistics opens source-specific publications and charts for a selected year range; Reports creates structured Word documents. The app's main window also includes recent changes and access to Scopus Coverage and other tools.

How do I update the program?

Use the built-in update check when available or download the most recent installer from GitHub Releases . Current installations normally keep local history under %LOCALAPPDATA%\ScienceTracker . If upgrading from an older installation under Program Files , Windows may request one-time administrator authorization to remove it. Back up local data before changing installation methods.

Is ScienceTracker free, and does it require a license?

ScienceTracker is free. Core application features do not require purchasing a license or activating a trial. Some external services, especially Scopus, impose their own API and subscription access rules; these are separate from ScienceTracker licensing.

Profiles, identifiers and API access

Which academic sources appear in ScienceTracker?

The visible research profiles are Scopus , Google Scholar and ORCID . OpenAlex is not a selectable statistics or reports profile; it remains an internal bibliographic source for matching, selected metadata checks and estimated Scopus self-citations. SCImago and Crossref are supporting sources, not separately monitored author profiles.

Why is OpenAlex no longer shown? Is it still used?

To make the dashboard easier to understand, OpenAlex's own author citation counts, h-index and statistics were removed from the visible interface. Its useful background procedures remain. ScienceTracker can resolve an OpenAlex author using the ORCID iD supplied in Settings, reuse its bibliographic records, and use OpenAlex citation relationships to estimate self-citations for matched Scopus works. An OpenAlex author profile and a public ORCID works list are not the same dataset.

Why does Scopus require an API key?

ScienceTracker retrieves Scopus metrics and publications through the official Elsevier API. Request a key at dev.elsevier.com ; a link appears next to the API key field in Settings. A key does not guarantee access to every Elsevier endpoint: entitlements and possible institutional authorization control which data can be retrieved.

Scopus works at my institution but not at home. What should I check?

Elsevier API permissions can depend on the API key, institution, network, subscription and authorization method. Confirm the exact HTTP error and endpoint. If your institution provides an Institutional Token , enter it in the optional field; otherwise contact Elsevier or your institution to clarify access. Registering a new personal key does not necessarily grant off-campus institutional privileges.

Is the Scopus API key or ORCID iD mandatory for all functions?

No. Google Scholar can be monitored independently. Scopus features require a working Scopus ID and API key. ORCID public-work features need the ORCID iD. Advanced Scopus matching and self-citation estimation benefit from ORCID-resolved background OpenAlex data. The Settings hint is a local completeness reminder : it disappears when the IDs pass format checks and the API-key field is nonempty; it does not test whether the API key has server-side access.

Why do my Scopus, Google Scholar and ORCID publication totals differ?

They cover different subsets of work. Scopus and Scholar track publications with their own indexing rules; ORCID lists publicly visible works recorded in the researcher's ORCID profile. Works may be missing, private, duplicated or typed differently. ORCID does not provide citation totals or an h-index. ScienceTracker does not add together unlike metrics or assume that ORCID and OpenAlex contain identical works.

Why does Google Scholar sometimes fail to refresh?

Google Scholar does not offer a guaranteed public researcher-profile API for this use case. Rate limits, CAPTCHA challenges, profile privacy and website changes can prevent automated updates. Check that your public profile loads in a browser, increase the checking interval and retry later. A failed refresh is not zero citations.

How is the ORCID publication list obtained?

ScienceTracker retrieves publicly visible ORCID works and caches the list for reuse by Statistics and Scopus Coverage. It currently reads the ORCID site's public worksPage.json interface, which is not the stable official Public API and could change without notice. Records that are not public cannot be recovered from the public listing.

Statistics, quartiles and publication analysis

What does each profile show in the main window?

Scopus shows publication count, citations, h-index, progress to the next h-index, Scopus Coverage and estimated self-citations. Google Scholar shows publications, citations, h-index and the next-h-index progress. ORCID shows the total number of public works and counts in Articles, Abstracts (conference outputs), Books and Other. ORCID has no citation-based gauges.

What statistics and charts are available for Scopus?

Selected-year publication lists, citations, available document types, DOI, open-access indicators and SCImago quartiles; publications closest to increasing h-index; charts for works/citations, available h-index history, publication quartiles and exact citation-count distribution. Some charts require enough source or locally retained data.

How does Google Scholar Statistics work now?

ScienceTracker displays the already retrieved publication list, available citation data, citation distributions and publications closest to raising h-index. It no longer performs automatic article/other classification or SCImago quartile determination for Google Scholar. When the profile supplies a DOI, it is clickable. If DOI is missing but an identifiable citation record is available, the app can link directly to that Google Scholar record.

What does ORCID Statistics include?

Public ORCID works for the selected publication-year range, a histogram of works by publication year , and a chart of Articles / Abstracts / Books / Other . Works with no year are not assigned an artificial date. Neither citations nor h-index nor SCImago quartiles are included. Statistics can be copied, opened in HTML and exported to Word.

What counts as an ORCID “Abstract”?

The interface's Abstracts category groups conference-related ORCID work types: conference abstracts, papers, posters, presentations, proceedings and other conference outputs. It is an umbrella label; not all of those items are literally abstracts. Articles include journal/magazine/newspaper articles and reviews; Books include books, chapters, edited books and book reviews; all other native work types fall into Other. Categories are mutually exclusive and the original ORCID type is preserved.

How are SCImago quartiles calculated?

Only Scopus works classified as journal articles undergo SCImago matching. ScienceTracker matches the publication year and journal (ISSN first, then suitable title matching) against the appropriate annual catalog. If a journal has several subject-category quartiles, it selects the most frequent quartile ; a tie is resolved in favor of the worse quartile (for example, Q3 rather than Q2). This derived value is not necessarily the site's SJR Best Quartile. If subject-category quartiles are missing, ScienceTracker can use the catalog's Best Quartile field as a fallback; this fallback cannot establish whether the categories disagree.

What does an asterisk next to a quartile (for example, Q2*) mean?

An asterisk means the journal has different quartiles in different subject categories for that publication year . The automatically chosen quartile still follows the normal majority/tie rule, but the value relevant to an individual paper needs manual verification . The explanatory note is shown after the publication list and in supported exports. Several categories that all share the same Q do not require the asterisk.

Why does an article have no quartile, and why can first-time resolution be slow?

Possible causes include missing or inconsistent ISSN/title metadata, journals absent from that year's SCImago catalog, and items classified as non-journal publications. A first-time run may download full annual SCImago catalogs for multiple publication years; it can take a while even for a modest number of works. Recent versions optimize matching and cache results, but connectivity and SCImago response times still matter. “No quartile” is not a quality judgement.

What does “closest to the next h-index” mean?

For Scopus and Google Scholar, ScienceTracker identifies existing works whose additional citations would contribute to reaching the next h-index threshold. It is a mathematical calculation based on available per-publication citations, not a prediction of future citations. ORCID cannot offer this calculation because it has no citation data.

Why does my Scopus chart say “Citation Overview unavailable”?

The Scopus Citation Overview API can require access permissions that are not included with a given API key. If available, calendar-year citation counts may be used. Otherwise the chart shows the current number of citations to works grouped by their publication year — not the number of citations actually received in each calendar year. These two measures are different; the chart includes an explanatory fallback note.

How are Scopus self-citations estimated?

ScienceTracker matches Scopus publications to OpenAlex records and examines OpenAlex citing/cited-work relationships and author IDs. It reports an estimate , not an official Scopus self-citation measure, and shows information about matched-work coverage. This analysis can make OpenAlex API requests but caches prior results to avoid unnecessary recomputation.

What is Scopus Coverage?

The Scopus Coverage window contains Google Scholar and ORCID tabs. It matches candidate works to your Scopus profile using bibliographic evidence and identifies likely matches, uncertain cases and records worth checking. It cannot modify Scopus, and absence of a match does not prove a work should be indexed. Some deeper checks can require external requests, depending on the chosen procedure.

Why can a Scopus paper have no DOI or show “Closed access” even if the publisher provides it?

The Scopus API and publisher metadata can be incomplete or disagree. ScienceTracker can attempt a conservative local-only refinement using already downloaded OpenAlex records and a local Crossref cache , without making new requests as part of that refinement. If no reliable match exists locally, the original source data remain. Open Access labels across databases can differ, so check the publisher before drawing a definitive conclusion.

Can I export statistics and reports?

Yes. Profile Statistics supports copy, HTML viewing and Word export, with appropriate charts. The separate Reports tool creates a Research Activity Report, Selected Research Outputs report (five or ten works) or Research Impact Snapshot. Scopus and Google Scholar have citation-related fields; ORCID reports do not invent citations or h-index . OpenAlex is not a report-source choice.

Notifications, updates and other tools

How do I connect Telegram?

Open Settings → Telegram notifications , select Connect Telegram , follow the generated link and start the bot. Sign in to your Telegram account in the browser or desktop app before connecting. Use Send test when the status shows Connected. If an attempt was not completed or failed, the connection button becomes available for another attempt.

Will I receive duplicate Telegram alerts from home and work PCs?

With the compatible ScienceTracker app and notification backend, the same reported metric state is intended to be sent once per connected Telegram account, even across multiple computers. The PCs maintain separate local histories, so this is not profile synchronization. A previous installation or unexpected backend behavior may differ.

Why did Windows notify me without a Telegram message?

Windows and Telegram are different notification channels. Check the Telegram connection, send a test, and confirm your network works. The backend may deliberately suppress an event already delivered from another PC. Test notifications are separate from metric-change deduplication.

How often does ScienceTracker check profiles?

You can choose an interval of one hour or more . Faster checking increases the risk of provider-side rate limits, particularly for Google Scholar and some OpenAlex operations. Longer intervals are often more reliable for background monitoring.

What is the National System of Researchers of Ukraine field?

An optional application number in Settings can be used for the separate National System of Researchers of Ukraine ranking display when public source information is available. It is not required to retrieve Scopus, Scholar or ORCID records, nor for SCImago quartile resolution.

Troubleshooting, storage and privacy

Why does Windows SmartScreen show “Unknown Publisher”?

The GitHub installer may not have a digital code-signing certificate. A SmartScreen warning alone does not prove the installer is safe or malicious. Download from official Releases , verify the file's origin and proceed only if you trust it.

Why are some statistics or charts not available on first launch?

A new installation has no local source history or cached publication data. Allow the initial Scopus/Scholar/ORCID refresh to complete. The ORCID statistics loader waits for the existing background public-works request rather than intentionally starting a second one. SCImago imports can continue after basic metrics appear. If an upstream source fails, its statistics may remain unavailable until a later successful update.

Where are my data and diagnostic logs stored?

ScienceTracker stores history and caches under %LOCALAPPDATA%\ScienceTracker\ . The principal history file is stats_history.json (a .bak backup may also exist); the SQLite cache is science_tracker_cache.sqlite3 and diagnostics are written to update_diagnostics.log . Back up the whole directory before manual troubleshooting; uninstalling and reinstalling should not be treated as a backup strategy.

Why are two ScienceTracker installations listed in Windows?

Older releases could install for all users under Program Files , while newer releases install for the current user. A migration-enabled installer attempts to remove legacy copies. Windows may require one-time administrator approval to remove a machine-wide copy; it cannot always be done without elevated privileges. Do not manually remove your data folder while resolving duplicates.

Can ScienceTracker restore all the metrics I had on another PC?

No automatic cloud history synchronization is provided. Each PC keeps its own historical snapshots and caches. If you need to move history, preserve the original files and backups carefully rather than overwriting current data without checking. Telegram deduplication is only a notification-delivery feature.

What data are sent to Telegram or external academic services?

The selected academic sources receive retrieval requests according to their respective APIs and websites. For Telegram, the optional backend processes the identifiers and account-linking/alert information required for notifications. Local citation-history files are not synchronized through Telegram. Do not publish Scopus API keys, Institutional Tokens or connection tokens in support requests.

Where should I report bugs or request help?

Use GitHub Issues or the support address in the README. Include ScienceTracker version, Windows version, relevant profile (Scopus, Google Scholar or ORCID), exact error text, steps to reproduce, and screenshots if helpful. Remove keys and other private credentials before sharing logs or screenshots.
