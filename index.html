Why Are There Two Versions of ScienceTracker?

ScienceTracker is distributed through Microsoft Store and GitHub. Both versions offer identical functionality and are completely free to use. The only differences are how they are installed and updated.

Microsoft Store — the recommended option for most users. Before publication, the application undergoes official Microsoft certification, which includes checks for compliance with Store requirements, security, and functionality. The application is installed directly from Microsoft Store and receives automatic updates through the Store.

GitHub — an alternative for users who prefer a traditional Windows installer or do not use Microsoft Store. The application is installed using an EXE installer and receives updates directly from GitHub Releases, without undergoing Microsoft Store certification.

Which Version Should You Choose?

Choose Microsoft Store if you prefer easy installation, automatic updates, and the additional assurance of Microsoft's certification process.

Choose GitHub if you prefer greater control over installation and direct access to developer releases.

Trust, privacy & installation

  • Local-first storage: metric history, analytics caches, and supporting metadata are stored locally on your Windows device.
  • No intentional collection or sale of personal user telemetry: ScienceTracker does not intentionally collect or sell personal user telemetry, passwords, or academic-service credentials.
  • Telegram is optional: if Telegram notifications are enabled, the notification service stores the minimum connection information needed to associate the installation with the connected Telegram account and deliver notifications.
  • Scopus API key: required only when Scopus data are enabled.
  • Scopus API compliance: Elsevier has confirmed in writing that ScienceTracker may be publicly distributed as a free, non-commercial application without a separate API partner agreement or additional authorization, provided each user obtains and uses their own individual API key.
  • Journal rankings: ScienceTracker uses data from SCImago Journal & Country Rank to assign journal quartiles (Q1–Q4). Source: SCImago, (n.d.). SJR — SCImago Journal & Country Rank [Portal].
  • Academic data sources: ScienceTracker uses academic profile information and bibliographic metadata from Google Scholar, Scopus, OpenAlex, ORCID and Crossref. Coverage, availability and accuracy depend on the respective providers.
  • Independent software: ScienceTracker is independently developed and is not affiliated with or endorsed by Google, Elsevier, OpenAlex, ORCID, Crossref or SCImago.
  • Installer transparency: ScienceTracker is distributed through its public GitHub repository and GitHub Releases. The current installer is not digitally signed, so Windows SmartScreen may display Unknown Publisher on first launch.
